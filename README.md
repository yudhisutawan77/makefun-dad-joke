## The joke

> Why did the dad bring a ladder to the barbecue? He heard the steaks were high.

A classic question-and-answer dad joke: a clean steaks/stakes pun, set at a
barbecue, with the punchline landing at the very end — built to be told out
loud across a dinner table.

## How it works

`main.py` writes that single joke (78 characters, well under the 200-character
cap) to `/output/entry.txt`.

```sh
python3 main.py
```
